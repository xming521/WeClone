# 数据安全

## 哪些内容会离开本机

- 绘制人生画像：抽取、整理和总结时，聊天内容会发送给你配置的模型服务（Codex 或 API）。开始前会提示并请你确认。模型的回答缓存在本地，已经抽取过的内容不会再次发送。
- 助手接入：助手读取到的条目会交给助手背后的模型服务。选择「全部」级别时，私密和敏感条目也包括在内。
- 微调分身：训练和推理都在本机运行。生成训练数据时，如果开启了在线 LLM 数据清洗（`online_llm_clear`）或图片转文字（`vision_api`），相应内容会发送给配置的 API。

## 存储模式

在 `settings.jsonc` 中设置：

```json
"security_args": {
    "storage_mode": "encrypted"
}
```

- `encrypted`：模板默认值。聊天数据及其衍生产物（聊天快照、画像、训练数据和微调模型）加密保存，文件以 `.enc` 结尾。加密模式暂不支持分布式训练。
- `plaintext`：明文保存。未设置 `security_args` 的旧配置使用明文。

存储模式在首次初始化后固定。切换模式需要在新的输出目录中从原始聊天重新生成全部数据。原始聊天和手动导出的明文文件不受 WeClone 管理，请自行保管。

## 密码

首次运行任务或打开网页时设置共用密码。网页登录使用这个密码，加密模式下命令行任务也用它解锁数据。

```bash
weclone-cli decrypt --input <加密文件> --output <新的明文文件>  # 导出明文
weclone-cli security-change-password                             # 使用旧密码修改，保留数据
weclone-cli server-reset-password                                # 忘记密码时重置
```

忘记密码无法恢复旧密文。重置密码后，需要在新的输出目录中从原始聊天重新生成数据。

## 密钥与令牌

`.weclone/` 目录保存用密码加密的数据密钥（`manifest.json`），以及助手和机器人的令牌记录（`assistant.sqlite3`、`bots.sqlite3`）。读取加密数据必须用到这个目录，请保留并备份。

- 两种令牌都只保存哈希，只在生成时显示一次，丢失后重新生成即可。
- 机器人令牌和 `bots.sqlite3` 放在一起就能解密全部数据，要像密码一样保管。修改密码后它仍然有效，重置密码后需要重新生成。

## 请求日志

WeClone 调用模型服务的请求记录在 `logs/llm_audit/` 中。加密模式只记录元数据，明文模式会记录完整的请求和回复。
