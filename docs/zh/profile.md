# 人生画像与助手接入

## 绘制人生画像

先按[准备数据](data.md)放好聊天记录，按[配置模型后端](installation.md#配置模型后端)选好模型，然后在项目根目录启动网页：

```bash
weclone-cli server
```

在浏览器中打开 http://127.0.0.1:5175 ，设置密码后进入「构建画像」页。还没有画像时首页会带你过去，之后从「设置 → 画像版本」进入。先选择用途：

- 个人助理：抽取画像和事件。
- 做分身：另外抽取语言风格，需要先安装[语言风格依赖](installation.md#语言风格依赖)。

页面会检查配置，列出缺少的设置和改法。通用 CSV 格式的聊天记录可以直接在这个页面上传，见[准备数据](data.md#通用-csv-格式)。API 后端还要填写模型的输入 Token 上限。勾选同意把聊天内容发送给模型服务后开始构建。构建在后台进程中运行，关掉网页也不会停止，页面显示每个阶段的进度，其他页面的顶栏显示「正在构建 n/N」。依次执行：

1. 准备聊天数据：按联系人整理文字消息，切分成对话段
2. 抽取画像记忆和事件记忆
3. 划分板块，分类并汇总记忆，为每条事实标注隐私级别和时效
4. 把每个板块的事实分成主题，生成画像层级
5. 生成板块总结
6. 抽取语言风格（仅 `--purpose clone`）

| 参数 | 说明 |
|---|---|
| `--output-dir <目录>` | 结果目录，必须是新目录。默认在 `dataset/res_csv/agent/profile_runs/` 下按时间新建 |
| `--max-context-tokens <上限>` | 记忆整理和画像生成的输入 Token 上限。Codex 后端默认读取模型的上下文长度，API 后端必须指定 |
| `--yes` | 跳过发送确认，用于脚本 |

构建完成后，如果正在显示的画像还没有审核过，网页直接换成新画像；已经审核过时，审核记录留在旧版本里，由你点「打开新画像」切换。所有版本都列在「设置 → 画像版本」里，可以随时切回。同一时间只能有一次构建在运行。

模型的回答按输入内容缓存在 `dataset/res_csv/agent/llm_cache.sqlite`。构建失败或取消后点「重新构建」，会在新的结果目录重跑，只请求缺少的部分。删除该文件则全部重新请求。

### 在命令行构建

```bash
weclone-cli build-profile
```

运行时选择用途，也可以用 `--purpose assistant` 或 `--purpose clone` 直接指定。开始前做和网页相同的检查，有问题会全部列出后退出；之后显示模型后端并请你确认。结果同样出现在网页的「画像版本」里。

## 在网页上审核

```bash
weclone-cli server                    # 打开网页上选过的版本，没选过则打开最新一次
weclone-cli server --run <结果目录>   # 这次启动打开指定的一次结果
weclone-cli server --demo             # 打开自带的合成画像，--demo en 为英文版
```

`--demo` 用来在生成自己的画像之前先看看网页效果。审核记录和密码只保存在临时目录，退出后删除，不影响你自己的数据。登录页会显示密码 `demo`。

在浏览器中打开 http://127.0.0.1:5175 ，使用共用密码登录（见[数据安全](security.md#密码)）。网页按浏览器语言显示中文或英文，可以用顶栏的「中/EN」切换：

| 页面 | 用途 |
|---|---|
| 人生画像（`#/`） | 按板块和主题浏览画像，逐条采纳、修改或不采纳，查看每条事实出自的聊天 |
| 语言风格（`#/style`） | 查看 `--purpose clone` 抽取的语言风格 |
| 板块总结（`#/summary`） | 按隐私级别生成和确认各板块的总结，复制给个人助理 |
| 助手接入（`#/assistant`） | 设置助手能读取的级别和板块，生成令牌 |
| 机器人接入（`#/bots`） | 生成聊天机器人调用分身的令牌，见[接入聊天机器人](chatbot.md) |
| 构建画像（`#/build`） | 检查配置，从聊天记录构建新画像，查看进度。版本在「设置 → 画像版本」里切换 |

审核记录保存在该次结果目录的 `profile_hierarchy/` 中，只属于这一次结果。

## 接入 AI 助理

Claude Code、Codex 等支持 MCP 的助手可以读取你的人生画像：

1. 在「板块总结」页确认要提供的总结。只有确认过的总结会提供给助手。
2. 在「助手接入」页选择隐私级别和开放的板块，生成令牌。
3. 按页面上的命令配置 Claude Code 或 Codex。所有助手共用这一个令牌，修改级别和板块后，从助手的下一次调用起生效。

助手通过 MCP 连接 `http://127.0.0.1:5175/mcp`，使用两个只读工具：

- `weclone_profile`：返回已确认的板块总结。
- `weclone_search`：按关键词或板块查找画像条目，包括待审核的条目，不包括不采纳的条目。

助手使用期间要保持 `weclone-cli server` 运行。加密模式下，还要在「助手接入」页打开「允许助手读取」并选择时长，到时间或服务重启后需要重新打开。每次调用都会记录在审核数据库中。

不支持 MCP 的助理，可以在「板块总结」页选择隐私级别，一键复制页面上的导出文本，粘贴到助理的「关于我」、自定义指令或 USER.md。导出文本只包含确认过的总结。贴出去的内容收不回来，复制前请再看一遍。

> [!WARNING]
> 选择「全部」级别时，私密和敏感条目也会交给助手背后的云端模型。
